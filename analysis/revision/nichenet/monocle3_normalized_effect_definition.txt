extract_coefficient_helper, lines 408-428, uses pseudo_count=0.01 and:
normalized_effect = log2((linkinv(beta0 + beta) + 0.01)/(linkinv(beta0) + 0.01)).
For the default quasipoisson log link this becomes:
log2((exp(beta0 + beta) + 0.01)/(exp(beta0) + 0.01)).
This is not log2(beta/intercept). Figures in this revision retain the stored field name Monocle3 normalized_effect and sign-orient it toward the indicated donor.
